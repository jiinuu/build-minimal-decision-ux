# Build Minimal Decision UX

A Codex skill for designing and reviewing operational interfaces around the user's primary completion event. It favors fewer decisions and steps, clear evidence for recommendations, accessible interactions, and measurable task outcomes.

## Install

Place this repository at `~/.codex/skills/build-minimal-decision-ux` (or the equivalent skills directory configured for your Codex installation), then restart or refresh Codex's skill inventory.

## Use

Ask Codex: `Use $build-minimal-decision-ux to simplify this workflow.`

The skill contains:

- `SKILL.md` — workflow and design rules
- `references/research-foundations.md` — research and design-system source matrix
- `agents/openai.yaml` — display metadata

For visual-direction searches, the skill can use the separately installed [UI UX Pro Max skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). That external project is **not bundled** here and has its own license. Without it, the core audit and design guidance remains usable.

The linked research and design systems belong to their respective authors. This repository provides short summaries and links, not copies of those works.
